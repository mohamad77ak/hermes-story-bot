# استوری خودکار قیمت – هرمس گلد

هر روز نزدیک ساعت ۱۲ و ۱۸ (وقت تهران) قیمت‌ها را می‌گیرد، روی طرح خودتان می‌نویسد و استوری می‌کند.

منبع قیمت: پروژهٔ عمومی Iran Market Data (فایل JSON، مجوز MIT، داده از TGJU).
نیازی به ثبت‌نام یا کلید قیمت نیست. قیمت‌ها هر ۳۰ دقیقه تازه می‌شوند،
پس ممکن است تا حدود نیم‌ساعت با بازار فاصله داشته باشند. ساعتی که روی استوری می‌آید، زمان واقعی داده است.

## راه‌اندازی (فقط یک‌بار)

۱. در سایت github.com حساب بسازید و یک ریپوی جدید با گزینهٔ **Public** بسازید.
   (عمومی بودن لازم است تا اینستاگرام بتواند عکس را بردارد. هیچ رمزی داخل فایل‌ها نیست.)

۲. همهٔ فایل‌ها را آپلود کنید، به‌همراه پوشهٔ `assets` (قالب طرح و فونت داخل آن است).
   اگر پوشهٔ مخفی `.github` آپلود نشد: دکمهٔ **Add file** ← **Create new file** را بزنید،
   در کادر نام بنویسید `.github/workflows/story.yml` و محتوای فایل story.yml را داخلش کپی کنید.

۳. دو کلید را وارد کنید. مسیر: **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**
   - `COMPOSIO_API_KEY` : از platform.composio.dev، بخش تنظیمات، کلید API
   - `COMPOSIO_CONNECTED_ACCOUNT_ID` : شناسهٔ اتصال اینستاگرام در داشبورد کامپوزیو

۴. اجازهٔ نوشتن بدهید. مسیر: **Settings** ← **Actions** ← **General** ← **Workflow permissions**
   گزینهٔ **Read and write permissions** را انتخاب و ذخیره کنید.

## آزمایش
- تب **Actions** ← **Hermes Story** ← **Run workflow** و `dry_run` را روی `true` بگذارید.
  فقط عکس ساخته می‌شود و منتشر نمی‌شود. عکس را از پایین صفحهٔ اجرا (قسمت Artifacts) ببینید و با بازار مقایسه کنید.
- چند روز اول حتماً قیمت‌های عکس را با بازار چک کنید.
- اگر درست بود، دوباره اجرا کنید و `dry_run` را `false` بگذارید تا یک استوری واقعی منتشر شود.
- بعد از آن همه‌چیز خودکار است.

## ایمنی
- اگر داده منبع بیش از ۱۰۰ دقیقه قدیمی باشد، قیمتی ناقص یا کهنه باشد، یا نسبت به دفعهٔ قبل بیش از ۸ درصد تغییر کند،
  استوری **منتشر نمی‌شود** و اجرا خطا می‌دهد.
- برای توقف: تب Actions ← Hermes Story ← سه‌نقطه ← **Disable workflow**.

## تغییر طرح
عکس جدید را با نام `template.jpg` (اندازه ۱۰۸۰×۱۹۱۲ و جای اعداد خالی) در پوشهٔ `assets` جایگزین کنید.
مختصات اعداد در بخش `LAYOUT` فایل `bot.py` است. نمادهای قیمت در بخش `ITEMS` است.
